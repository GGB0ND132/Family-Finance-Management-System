# 家庭收支管理系统前端实现 TODO

本清单依据 `docs/需求分析.md` v2.0 与 `docs/详细设计.md` 编写，技术基线为 React + TypeScript + Vite + Ant Design。实现时保留 `/api/v1` 接口边界，Mock 数据只用于页面演示，不能替代接口契约、权限校验和错误处理。

## 0. 完成定义

- [ ] 每个任务完成后补充接口、页面截图或测试记录。
- [ ] 所有写操作同时具备前端交互校验和后端最终校验；前端不得把权限判断当作安全边界。
- [ ] 所有业务请求携带当前 `family_id`：GET 使用查询参数，POST/PUT/PATCH 使用请求体，详情/DELETE 由后端反查家庭。
- [ ] 个人/家庭范围使用 `scope=personal|family`，切换状态写入当前业务页 URL；个人首页和家庭首页保持独立入口，不在首页顶部放范围切换。
- [ ] 所有流水、转账、导入和导出时间统一精确到分钟，展示格式为 `YYYY-MM-DD HH:mm`，传输使用 ISO 8601 或 `YYYY-MM-DDTHH:mm`。
- [ ] 每个页面覆盖加载中、空数据、接口错误、无权限、提交中和成功反馈状态。
- [ ] 完成 `npx tsc -b`、`npm run lint`、`npm run build`，并完成主要路由的浏览器验收。

## 1. 基础架构与设计系统

- [ ] 固化 Ant Design `ConfigProvider` 主题、中文 locale、响应式断点、颜色语义和间距令牌。
- [ ] 完善 `AppLayout`：侧栏导航、当前家庭信息、用户菜单、退出登录；首页顶部不出现个人/家庭切换。
- [ ] 建立统一 `ScopeToggle`/`useDataScope`：默认个人范围，保留其它 query 参数，切换后重新请求数据。
- [ ] 建立请求层：Axios `/api/v1` 前缀、JWT 注入、401 自动退出、统一错误结构、请求取消和重复提交保护。
- [ ] 建立通用组件：页面标题、范围栏、筛选栏、金额展示、分钟级时间展示、空状态、权限提示、确认弹窗、分页和表单错误提示。
- [ ] 建立领域类型：`DataScope`、成员、账户、分类、流水、转账、预算、导入批次和报表响应，避免页面自行定义不一致字段。
- [ ] 统一状态管理：认证状态、当前家庭、成员/账户/分类缓存、查询条件和提交状态；切换家庭后清理旧家庭缓存。
- [ ] 完成移动端适配：侧栏折叠、表格横向滚动、抽屉宽度、筛选条件换行和触控按钮尺寸。

## 2. 认证、用户与家庭

- [ ] 登录页：用户名、密码校验，提交 loading，401/账号不存在/网络错误提示，成功后进入个人首页。
- [ ] 注册页：用户名唯一性提示、密码至少 8 位、确认密码、注册成功跳转登录。
- [ ] 个人信息：修改昵称、修改密码（旧密码校验），成功后刷新用户信息。
- [ ] 创建/加入家庭页：创建家庭名称、邀请码输入、邀请码失效/过期/重复加入提示。
- [ ] 家庭成员管理页：成员列表、角色授予/撤销、移除成员、生成/失效邀请码；最后一名管理员不可被移除或降权。
- [ ] 权限展示：普通成员隐藏无权操作或显示明确无权限提示，管理员操作前展示影响范围。

## 3. 账户管理

- [ ] 账户列表支持个人/家庭范围：个人只显示当前成员账户，家庭按成员分组显示。
- [ ] 新增账户：名称、类型、所属成员、初始余额、备注；普通成员只能创建所属人为自己的账户。
- [ ] 编辑账户：允许修改名称、类型、所属人和备注；不得改写历史流水的资金归属人/录入人。
- [ ] 删除/销户流程：余额必须为 `0.00`；无历史引用物理删除，有历史引用转为销户并保留历史。
- [ ] 销户账户不进入新增流水、转账候选，也不计入当前个人/家庭资产；历史报表仍可查询。
- [ ] 前端校验余额为零、家庭成员归属和重复提交；后端 409/403 错误按统一提示展示。

## 4. 分类管理

- [ ] Tabs 分离收入分类和支出分类，初始化默认分类。
- [ ] 管理员可新增、编辑自定义分类：名称、方向、颜色、图标；同家庭同方向不能重名。
- [ ] 流水表单按收入/支出方向过滤分类，方向不匹配时前端阻止提交，后端再次校验。
- [ ] 被流水或预算引用的分类执行软删除/保留历史名称，不再进入新流水和预算候选。
- [ ] 预算页的“添加分类”只添加当前月份预算项目，不删除全局分类；需要全局分类时提供分类管理入口。

## 5. 收支流水

- [ ] 列表提供个人/家庭范围按钮，支持分页和时间、类型、账户、账户所属人、分类、资金归属人、录入人、金额范围筛选。
- [ ] 时间筛选使用 `RangePicker showTime`，边界精确到分钟；列表和详情显示发生时间、创建时间。
- [ ] 新增/编辑抽屉：类型、金额、账户、分类、资金归属人、发生时间、备注；录入人固定为当前登录用户。
- [ ] 选择类型后只展示同方向分类；金额必须大于 0，账户必须未销户且属于当前家庭。
- [ ] 个人范围按 `beneficiary_member_id` 过滤，家庭范围按当前家庭全部流水过滤；不要接受前端传入任意成员冒充个人身份。
- [ ] 编辑流水正确撤销旧账户影响并应用新账户影响；删除流水反向恢复余额。
- [ ] 普通成员只可维护账户所属人为自己、资金归属人为自己或自己录入的流水；管理员可维护家庭全部流水。
- [ ] 统一处理跨家庭、销户账户、分类方向不匹配、非正金额、无权限和并发更新错误。

## 6. 家庭内部转账

- [ ] 列表提供个人/家庭范围按钮；个人只显示当前成员作为转出方或转入方的记录。
- [ ] 表单只包含转出账户、转入账户、金额、发生时间（分钟级）和备注，不提供独立“方向”字段。
- [ ] 选择账户后自动展示账户所属成员；转出和转入账户不能相同，销户账户不可选择。
- [ ] 保存时前端校验金额、账户归属和权限；后端在一个事务中锁定账户并再次校验。
- [ ] 列表显示“转出账户 → 转入账户”、双方成员、金额、发生时间和录入人。
- [ ] 支持编辑和删除：编辑需恢复原转账影响后应用新影响，失败整体回滚；删除反向恢复余额。
- [ ] 转账不创建收入/支出流水，不计入收支、结余和预算；个人资产变化单独展示。

## 7. 个人首页与家庭首页

- [ ] 个人首页 `/personal`：默认当天，展示个人收入、支出、转出、转入、账户变动明细和个人资产。
- [ ] 支持日期选择、当天零数据空状态、个人账户余额汇总和快捷新增流水/转账。
- [ ] 家庭首页 `/family-dashboard`：展示家庭收入、支出、结余、总资产、预算进度、最近流水和成员对比。
- [ ] 两个首页为独立入口，顶部不出现个人/家庭范围切换；首页数据调用对应个人/家庭报表接口。
- [ ] 销户账户排除当前资产，历史月份明细仍可显示；转账仅作为资产流动展示。

## 8. 数据报表

- [ ] 报表页使用 URL `scope` 切换个人/家庭，并按范围调用对应 summary、trend、by-category 接口。
- [ ] 个人报表只显示个人趋势、分类占比和个人转账/资产变动，不渲染“成员对比”。
- [ ] 家庭报表显示家庭收支、结余、趋势、分类占比和成员收入/支出/资产/转账对比。
- [ ] 无数据时返回零值指标和空序列，前端展示可理解的空状态而不是空白图表。
- [ ] 图表金额、时间范围、成员口径与后端响应一致；转账不污染收入、支出、结余和预算。

## 9. 月度预算

- [ ] 预算页按个人/家庭和月份查询，状态键为 `scope + month + member_id`。
- [ ] 个人预算不存在时显示总预算 `¥0.00`、分类预算空状态；不得自动铺满全部分类。
- [ ] 支持从可用支出分类中添加当前月份预算项目，输入非负金额，并可移除当前项目。
- [ ] 移除预算项目不删除全局分类；创建可跨月份使用的分类仍走分类管理权限。
- [ ] 展示总预算、已用、剩余、使用率和预警：`<80%` 正常、`80%~100%` 预警、`>100%` 超支，预算为 0 时使用率按 0 处理。
- [ ] 个人预算本人可保存，家庭预算仅管理员可保存；复制上月预算必须复制同一范围。
- [ ] 支出、流水编辑/删除后预算执行额实时重新聚合；转账不计入预算。

## 10. 外部账单导入

- [ ] 三步流程：选择个人/家庭范围、家庭、目标账户和来源；上传 CSV/XLSX；字段映射、预览和确认。
- [ ] 个人范围目标账户默认当前成员账户，家庭范围可选择当前家庭未销户账户。
- [ ] 映射发生时间、金额、方向、分类、资金归属人、备注等字段；文件只有日期时补充当天 `00:00` 并提示。
- [ ] 预览展示有效、非法、重复行和错误原因；非法行禁止确认，重复行默认跳过。
- [ ] 重复键为“账户 + 分钟级发生时间 + 两位小数金额 + 去首尾空白备注”，同时检查数据库和当前批次。
- [ ] 确认前再次校验家庭、账户、分类、成员和销户状态；有效行批量写入与余额更新需支持整体回滚。
- [ ] 文件大小、扩展名、缺失列、非法时间/金额、无权限和后端错误均有明确反馈。

## 11. 流水导出

- [ ] 导出页提供个人/家庭范围、时间（分钟级）、类型、账户、账户所属人、资金归属人、录入人等筛选。
- [ ] CSV 使用 UTF-8 BOM；XLSX 调用 `/api/v1/exports/transactions` 并以 Blob 下载。
- [ ] 导出列至少包含：发生时间、类型、金额、账户、账户所属人、分类、资金归属人、录入人、备注、创建时间。
- [ ] 下载前校验范围和权限，错误 JSON Blob 先解析后展示统一错误信息。
- [ ] 下载完成后释放 `URL.createObjectURL`；文件名包含范围和日期条件。

## 12. 接口联调与错误处理

- [ ] 补齐 `accountsApi`、`categoriesApi`、`transactionsApi`、`transfersApi`、`budgetsApi`、`reportsApi`、`importsApi`、`exportsApi` 的请求/响应类型。
- [ ] 所有 GET 查询显式传 `family_id` 和必要的 `scope`；个人接口由后端根据 JWT 解析当前成员。
- [ ] 所有写接口携带 `family_id`、scope/member 信息和版本约定；前端不绕过 API 直接修改生产数据。
- [ ] 统一处理 400/401/403/404/409/422/500、网络断开、超时、取消请求和重复提交。
- [ ] 对接口响应做最小运行时校验，防止字段缺失导致页面白屏；记录可定位的错误日志，不泄露 Token。

## 13. 测试与验收

- [ ] 单元测试：金额格式化、分钟级时间格式化、范围过滤、预算使用率、转账余额变更和去重键。
- [ ] 组件测试：表单必填、方向匹配、销户账户禁选、余额非零提示、预算添加/删除分类、个人报表隐藏成员对比。
- [ ] 接口 Mock/契约测试：scope、family_id、member_id、权限错误、分页、Blob 响应和错误 Blob。
- [ ] 端到端流程：注册登录 → 创建/加入家庭 → 创建账户 → 记账 → 转账 → 设置预算 → 查看报表 → 导入 → 导出。
- [ ] 验证家庭隔离、个人/家庭切换、普通成员权限、管理员权限、销户后历史查询和事务失败回滚。
- [ ] 浏览器验收：桌面端与移动端主要断点、键盘可操作、焦点可见、空状态、加载状态、错误提示和分钟级时间显示。

## 14. 建议实现顺序

1. 基础架构、认证、当前家庭和统一范围状态。
2. 账户、分类及其权限与候选项过滤。
3. 收支流水和账户余额同步。
4. 内部转账及个人资产变动。
5. 个人首页、家庭首页和报表。
6. 个人/家庭预算及分类项目管理。
7. 导入预览确认和批量错误处理。
8. 导出筛选、CSV/XLSX 下载。
9. 联调、测试、响应式和无障碍验收。
